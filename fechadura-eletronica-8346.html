As quatro portas

AND

“Todos certos”

0·0 = 00·1 = 01·0 = 01·1 = 1

Só retorna 1 quando todas as entradas são 1. Aqui, recebe os 16 sinais de acerto produzidos pelo NOT e só libera a fechadura quando todos os bits coincidem.

Uma porta com 16 travas: todas precisam ser liberadas.
OR

“Qualquer um basta”

0+0 = 00+1 = 11+0 = 11+1 = 1

Retorna 1 se pelo menos uma entrada for 1. Por isso, não serve sozinha para validar uma senha: um único acerto já bastaria.

A saída liga se qualquer um dos interruptores for acionado.
NOT

“Inverte o sinal”

NOT 0 = 1NOT 1 = 0

Inverte cada resultado da XOR. Como XOR vale 0 quando os bits são iguais, NOT transforma esse 0 em 1 para marcar um bit correto.

Transforma “nenhuma diferença” em um sinal de acerto.
XOR

“São diferentes?”

0⊕0 = 00⊕1 = 11⊕0 = 11⊕1 = 0

Compara cada bit digitado com o bit de referência correspondente. XOR = 0 indica igualdade; XOR = 1 indica diferença.

Compara lado a lado e marca cada bit que divergiu.

Como a fechadura usa tudo isso

01
Digite quatro algarismos no teclado. Cada um é convertido para 4 bits; por exemplo, 8 vira 1000. A senha de referência 8346 corresponde a 1000 0011 0100 0110, totalizando 16 bits.
02
A porta XOR compara os 16 bits digitados com os 16 bits de referência. Em cada posição, bits iguais produzem 0; bits diferentes produzem 1.
03
Cada saída XOR passa por uma porta NOT: XOR = 0 vira NOT = 1 (bit correto); XOR = 1 vira NOT = 0 (bit incorreto).
04
A porta AND reúne os 16 resultados NOT. Ela só retorna 1 quando todos os 16 bits estão corretos e os quatro algarismos foram digitados.
05
AND = 1 → a fechadura abre. Se faltar um algarismo ou houver qualquer diferença, pelo menos um NOT será 0 e AND = 0 → permanece fechada.
